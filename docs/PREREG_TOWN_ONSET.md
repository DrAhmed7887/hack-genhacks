## 1. Question and hypotheses

On a fixed decision date before the season, can a nurse in each Madrid town schedule the nasal-steroid reminder so that it lands 7–28 days before that town's season onset more often than with today's single regional date?

- **H1 (place):** a town-level calendar (M1) beats a regional calendar (M0).
- **H2 (NASA POWER):** town calendar + pre-season heat sum (M2) beats the town calendar (M1).
- **H3 (NASA MODIS):** M2 + town greenness anomaly (M3) beats M2.

Each hypothesis is tested separately for olive and grass: 6 confirmatory comparisons in total. Nothing else is confirmatory.

**Clinical basis of the 7–28 day window:** nasal steroid started 4 weeks before ragweed season (M1); 3 weeks of prophylaxis beat a post-onset start, 1 week was cost-effective (M2); the best start time is unclear (C2). The window is a design choice drawn from those trials, not a guideline.

## 3. Season onset (TBD values must be filled and signed before loading)

- **Rule type: absolute concentration threshold**, never a percentage of the annual total (a percentage uses end-of-season data and misfires in olive's light years) *(Neon; the two rule types: PR1)*.
- **Grass onset:** first day of the first run of **[TBD-G: N days ≥ X grains/m³ with run sum ≥ Y]**. Source to read first: EAACI 2017 position paper on pollen season definitions (PR2, PMID 27874202; numbers are not in the abstract, full text needed). Neon proposed N = 5, X = 3, Y = 30: **unverified**.
- **Olive onset:** first day of the first run of **[TBD-O: N days ≥ X grains/m³]**. No verified source yet; Neon proposed 3 days ≥ 50, marked unsure by Neon itself. If no published olive definition is found, Ahmed picks one before loading and the choice is recorded as a judgement, not a standard.
- **Completeness rule** *(Neon)*: a station-season counts only if ≥ 90% of 1 Mar–30 Jun days have a value and no gap is longer than 3 days within ±10 days of the onset found. Incomplete station-seasons are excluded, never imputed. A zero is a value; an empty cell is missing.

## 4. Decision date and reminder date

- **Decision date t₀ (one per taxon, all towns, all years):** the 10th percentile of pooled station onset day-of-year in **1993–2005 only**, minus 28 days, rounded down to the 1st or 15th of the month. 1993–2005 are training years for every model, so setting t₀ from them does not touch a test year. Neon's suggestions (grass 15 Mar, olive 1 Apr) are checked against this rule, not adopted.
- **Information cut-off:** every input must have been available on t₀. NASA POWER: data up to t₀ − 7 days. MODIS: a composite counts only if its end date (start + 15 days) is ≤ t₀ − 5 days *(Neon)*. Trap data: up to t₀ − 3 days.
- **Reminder date:** remind = max(t₀, predicted onset − 18 days). 18 days ≈ the middle of the 7–28 day window.

## 5. Models

All models predict onset day-of-year per station and year from information available on t₀.

| ID | Model | Features |
|---|---|---|
| M0 | Regional calendar | Median onset of all stations in all previous years |
| M1 | Town calendar | Median onset of this station in previous years; if the station has < 5 previous valid seasons, the regional median plus the station's mean offset so far |
| M2 | Town + heat sum | Pooled linear model, onset = α(station) + β · GDD(1 Jan → t₀ − 7), NASA POWER at the station's grid cell; base temperature **[TBD-T: from literature; if none is verified, 5 °C for both taxa]**, never tuned |
| M3 | M2 + greenness | Adds the station's NDVI anomaly: latest eligible composite in a 2 km buffer minus that station's mean for the same composite day in previous years |
| M4 | Exploratory only | Gradient boosting, library defaults, no tuning, same features as M3. Reported, never promoted |

Olive only, exploratory: previous year's olive pollen total at the station (alternate bearing) added to M2. Reported, not confirmatory.

## 6. Validation

- **Expanding window, forward in time** *(Neon)*: to predict year y, fit on years < y only (medians, offsets, β, NDVI means, everything).
- **Test years: 2006–2026.** Every model is scored on exactly the same station-seasons. M3 needs ≥ 6 prior MODIS years, which 2006 gives (2000–2005).
- **The unit of inference is the year** *(Neon)*: the 11 traps share one region, so ~300 station-seasons are about 21 independent springs.

## 7. Metrics and decision rules

- **Primary: window hit rate (WHR).** Share of valid station-seasons with 7 ≤ onset − reminder ≤ 28 days; averaged over stations within a year, then over test years.
- **Secondary: late-reminder rate (LRR).** Share with onset − reminder < 7 days (the harmful failure). MAE in days is descriptive only.
- **Uncertainty:** paired bootstrap over test years (B = 5,000, whole years resampled, all stations of a year kept together). Olive sensitivity: 2-year moving-block bootstrap (alternate bearing). Six confirmatory comparisons → Bonferroni: 99.17% percentile intervals.
- **A hypothesis passes only if all three hold** *(Neon)*: ΔWHR ≥ +5 points, ΔLRR ≤ 0, and the 99.17% interval for ΔWHR is entirely above 0.
- **What gets shipped:** the simplest model whose chain of hypotheses passed (M0 → M1 → M2 → M3). If H1 fails, the product uses one regional date and says so.

## 8. External test (grass only)

Basel 1969–2025 (one station, so H1 cannot be tested there): M1 vs M2 with the same rules, onset definition, metrics and expanding window, test years from the 21st valid season onward. Luxembourg is added only under the condition in Section 2. A result that holds in Madrid but not Basel is reported as Madrid-specific.
