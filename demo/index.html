Methodology

Season Definition

Derived from training years (2021-2023) only. First/last day with ≥1 grain/m³ observed pollen, clipped to named months (olive Apr-Jun, grass Mar-Jul, birch Mar-Apr).

Rules Evaluated

P0: Observed(D-1) ≥ T (persistence baseline)
P1: API(D-1) ≥ T (API persistence)
P2: API(D) ≥ T (API's own forecast, kill-check baseline)
R1: mean(API(D-1), API(D)) ≥ T (two-day exposure)
R2: First in-season day where max(API(D..D+3)) ≥ T (pre-peak alert)
C0: Climatology - day-of-year share of prior high days ≥ 0.5

Cities Scored

Madrid: olive, grass (Comunidad de Madrid, FACF)
Basel: birch, grass (MeteoSwiss, PBS)
Zurich: birch, grass (MeteoSwiss, PZH)
Valencia: demo only, never scored

Data Sources

Modelled pollen: Open-Meteo Air Quality API, CAMS European air quality forecasts, ENSEMBLE data (licence CC BY 4.0; free tier for non-commercial use). Observed pollen: Comunidad de Madrid, Histórico de mediciones de polen (Creative Commons Attribution, CC BY); MeteoSwiss (CC-BY). Synthetic patients (seed 20261120).

Limits & Known Issues

  • Trap-versus-grid mismatch: Point measurements vs 11 km grid model resolution
  • R2 lead over P2 is look-ahead: R2 uses API values for D..D+3, so by construction it fires up to 3 days before P2 and never after, and the +2.88-day difference is not evidence of better skill; the archived D+1..D+3 values may be better than a live 3-day forecast
  • Open-Meteo has no pollen category: No stated validation; docs call it a forecast, not measurement
  • Thresholds from single-centre studies: New large panel found no consensus thresholds (T5)
  • Only 5 seasons: Limited statistical power; intervals will be wide
  • Pre-Oct-2023 API source unverified: See DATA_PLAN section 2.1
  • Measures alert quality only: No data on reduced symptoms, visits, or patient outcomes
  • Madrid P2 recall below 50%: Both olive (13.6%) and grass (31.4%) fail this threshold - see kill-check check3
